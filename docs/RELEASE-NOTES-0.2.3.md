# PlayStation 0.2.3

随客户端整合包1.4.102／服务端1.4.102-server.1发布。

- 底座改为原版单掌机槽：打开底座即正常保存手持游戏，直接从背包放入或取出，不再有“取出”按钮。机器身份、整卡和存档保持。
- 修复Wii黑屏：前端不再每帧覆盖Dolphin的帧缓冲绑定；主机设备页改用原版灰色界面，并显示真实的Wii启动提示。
- 全屏可按顺时针0/90/180/270度旋转，双屏触摸同步旋转；方向按游戏内容记在本机`config/muxi-console-display.json`。
- 纯画面全屏新增上下/左右双屏布局；左右时上屏在左、下屏在右，各自保持比例，触摸按实际显示框映射。布局与旋转分别记忆。
- 全屏不再用黑底遮住世界；原生F3和聊天显示在游戏上层，按T或/打开聊天不会多输入字符，Enter或Esc回到同一局。

安装文件：

- 主体`muxi-console-0.2.3+mc1.21.1.jar`，客户端与服务端安装。
- 运行库`muxi-console-runtime-1.0.1+mc1.21.1.jar`，仅客户端安装；含Wii修复，主体要求至少1.0.1。
- `muxi-console-runtime-1.0.1-sources.zip`为运行库1.0.1的完整对应源码附件，独立下载，运行游戏无需安装。

整合包会自动替换；手工安装须同时换掉旧的0.2.2主体和1.0.0运行库。服务端只需主体。

正式构建62组测试通过。主体相对已实测的0.2.3-dev.4候选只改版本元数据，运行库只多源码交付说明；dev.1至dev.4各自的真实Minecraft验收沿用，整合包1.4.102候选另做了双端启动、登录与正常退出。3DS布局只做了几何检查，商业游戏、实体手柄和性能不在本次验收范围内。
