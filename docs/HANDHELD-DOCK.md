# 手持掌机、底座与薄大屏

本轮按用户要求扩展独立掌机，Cartridge或附魔台模组的实现不作输入。整合包中已核对存在Easy Magic 21.1.4；[作者说明](https://www.curseforge.com/minecraft/mc-mods/easy-magic)也描述了附魔台保留并悬浮展示物品。底座只参考视觉体验，模型和动画由本仓实现，不增加对Easy Magic的依赖。

## 操作

装入兼容卡带后，拿在主手或副手即可启动同一局，画面显示在真实掌机屏幕上，不自动打开全屏。方向键、未与世界操作冲突的按键和已启用的手柄可直接操作；按F进入手持操作视角，使用该平台保存的完整键位。右键进入全屏，F在游戏界面中切换全屏与世界视角。两种视角共用同一运行进程和存档。

F8释放操作并保留控制席，可在世界中连接浏览器显示面；再次按F8返回。Esc正常保存并离开，同一卡带仍拿在手上时不会立即自动重开；收起再拿出可继续。切换热栏将掌机收进自己的背包时，停止游戏输入并等待正常保存。死亡或将卡丢到地上不作为可靠保存入口，应先正常离开。

放置掌机底座，将已正常退出的掌机右键装入。底座保存完整原物品，包括机型、卡带身份、自定义名称和其他数据；不会额外复制一张卡。底座自带一个控制席，可接入控制器；使用底座面板开机、连接附近屏幕和选择控制席。取出前先保存并离开，取回的仍是同一台掌机。直接破坏正在运行的设备只保证保留最近已提交的存档。

## 展示与屏幕

底座只有低矮底板和插槽；安装的掌机在其上方缓慢旋转，无上下漂浮。显示的是实际放入的机型；活动画面只来自对应底座会话。

新放置的内置屏幕默认宽3格、高2格，厚2/16格。六格都是真实占用，四个水平朝向均可放置；空间不足时整面不放置、不消耗屏幕。拆掉任意一格会收起整面，只掉落一个屏幕物品。新屏的外观为3:2，具体游戏按原始比例留黑边，不拉伸或裁切。旧世界的单格屏幕继续保持原尺寸。
