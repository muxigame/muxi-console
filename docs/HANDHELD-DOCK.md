# 手持掌机、底座与薄大屏

本轮按用户要求扩展独立掌机，Cartridge或附魔台模组的实现不作输入。整合包中已核对存在Easy Magic 21.1.4；[作者说明](https://www.curseforge.com/minecraft/mc-mods/easy-magic)也描述了附魔台保留并悬浮展示物品。底座只参考视觉体验，模型和动画由本仓实现，不增加对Easy Magic的依赖。

## 操作

掌机当前为一个完整实体卡槽：背包中用鼠标拿卡右键掌机装入，空鼠标右键取出，也支持反向拿掌机右键明确卡槽；不再自动扫描背包第一张。实际卡在外部槽口显示，首次缺缓存时内屏显示真实加载进度，ROM与已提交存档都在当前服务器世界目录。完整数据、旧格式、转交/缓存和[本轮验收](CARTRIDGE-SLOTS.md)另列。

装入兼容卡带后，拿在主手或副手即可启动同一局，画面显示在真实掌机屏幕上，不自动打开全屏。普通拿着时输入交给Minecraft，游戏收到中立输入；选中时物品栏上方短暂提示“右键切换全屏模式，Esc退出全屏”。右键先进入完整机身放大的全屏，再右键切换只有游戏画面的全屏，继续右键往返；两种模式共用同一运行进程与存档。纯屏幕按原比例最大化到一边并保留细边框，不拉伸、不裁切；界面没有设置按钮、常驻说明或玩家状态条。

第一人称会显示玩家当前皮肤手臂。主手且副手为空时双手支撑；另一手有物时单手支撑，主副手的实际左右遵从Minecraft惯用手设置。九款掌机的机身和动作键已收薄收细，Start/Select/Option使用像素圆端胶囊；按下时整颗实际钮帽包括边缘/侧面变为天蓝色，松开恢复。全屏游玩时不会同时走路、攻击或切换物品；设置、失焦、退出全屏与离开会清空按住状态。按键完全使用Minecraft原生控制设置，完整默认键及保存方法见[玩家指南](USER-GUIDE.md#按键和手柄)。

Esc退出全屏并保留控制席，可在世界中连接浏览器显示面；右键掌机返回。F/F8不再承担切换或退出职责。切换热栏将掌机收进自己的背包时，停止游戏输入并等待正常保存。死亡或将卡丢到地上不作为可靠保存入口，应先正常离开。

放置掌机底座，将已正常退出的掌机右键装入。底座保存完整原物品，包括机型、卡带身份、自定义名称和其他数据；不会额外复制一张卡。底座自带一个控制席，可接入控制器；使用底座面板开机、连接附近屏幕和选择控制席。取出前先保存并离开，取回的仍是同一台掌机。直接破坏正在运行的设备只保证保留最近已提交的存档。

## 展示与屏幕

底座只有低矮底板和插槽；安装的掌机在其上方缓慢旋转，无上下漂浮。显示的是实际放入的机型；活动画面只来自对应底座会话。

新电脑显示器占宽2格、高2格、深1格范围，包含薄窄框16:9面板、支架、低底座和背部散热/接口。四格都是真实占用，四个水平朝向均可放置；空间不足时整台不放置、不消耗屏幕。拆掉任意一格会收起整台，只掉落一个屏幕物品。游戏继续按自身比例留黑边，不拉伸或裁切。

旧六片屏完整加载且可安全迁移时，原位改为四片、移除多余一列，保留身份/原点/连接，不额外掉物。异常附带物保留原屏。旧单格周围空闲时升级，受阻时保留新的单格外观并等待空间可用，不能挤掉邻块；变化过程中保存原状态和实体数据，失败时恢复仍属于本事务的写入位置。
