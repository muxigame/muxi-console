# 木犀游戏机玩家指南

服务端和客户端安装相同候选版本。当前面向Windows x86-64、Minecraft1.21.1 / NeoForge21.1.250。游戏机不附带商业游戏或原厂BIOS，请准备自己有权使用的文件。支持平台和实测边界见 [平台说明](PLATFORM-COMPLETION.md)；当前仍是未发布开发候选。

## 刻录自己的卡带

1. 在物品栏准备空白卡带，使用刻录机。
2. 点击“选择文件”，或将一个游戏文件拖入窗口。通常可自动识别；有歧义时手选平台。
3. 确认本次文件及使用的授权声明，再点击“上传并刻录”。声明默认不勾选；更换文件、平台或街机依赖后须重新确认。
4. 成功后取得可转交的实体卡带。主机、掌机与卡带分别选择，卡带不会永久绑定上传者。

街机选择原名 `driver.zip`，例如驱动名为 `example` 时使用 `example.zip`。需要parent或BIOS依赖的游戏，点“添加街机父集 / BIOS”选择自己有权使用、保留原名的ZIP；不要解压后混在一个随意命名的包里。刻录器会将主ZIP和依赖准备成 `.mxarc` 后整体校验；已有合法 `.mxarc` 也可选择。模组不提供这些游戏或BIOS文件。

卡带存档按实体卡带身份保存，内容按哈希去重。转交卡带前正常离开游戏，让最近进度保存完成；已取得的本地ROM缓存无法远程撤回。

服务器的ROM原件及已提交存档都在当前世界的 `muxi-console/content`、`muxi-console/states` 中。备份整个世界会同时保留玩家、设备及其中的卡带身份；客户端ROM缓存不代替世界存档。路径、备份范围与传输阶段见[实体卡槽说明](CARTRIDGE-SLOTS.md)。

## 桌机、屏幕与多人

放置主机，空手使用打开设备面板。空机且关机时可切换机型；选择对应机身后插入兼容卡带，外壳会保持原机型。可连接附近的木犀屏幕；自带显示面的机体直接显示游戏画面。新显示器占宽2格、高2格、深1格的空间，面板本身为薄窄框，下面有支架和底座；任意一格拆除会收起整台，只掉落一件屏幕。旧六格屏会安全缩为四格；旧单格屏周围可用时升级，受阻时保留原位，不挤掉邻块。

手持木犀控制器接入主机，启动后选择P1；其他玩家用自己的控制器选择空闲P2等接口。可用人数取决于机型和平台，单人机台与双人机台分别提供相应接口。Esc退出全屏并释放输入，控制席仍保留；需要取卡时，在当前设备面板点“保存并离开游戏”，等待保存完成后再取出。运行或保存中不允许拔卡；电源停止不作为最新进度已提交的保证。

N64和MAME由主控制席运行一份游戏，其他已占席玩家收取同一真实音画并提交自己的输入。共享画面最高20帧/秒，复杂画面可能降低清晰度；声音为48kHz双声道。主控正常离开会保存并结束该轮，下一位重新以P1启动可继续已保存进度。

## 掌机与机型

使用空掌机，先选择机型。每台掌机容纳一张完整卡带：背包中鼠标拿起兼容卡带，右键掌机装入；空鼠标右键掌机取出。也可以鼠标拿着掌机右键明确的卡带槽装入，或右键空槽取出。快捷方式是主手掌机、另一只手拿指定卡带后使用；不会自动选择背包中的第一张卡。卡带原身份、名称和自定义数据随原物品保留，满槽、不兼容和运行/保存中会拒绝插拔。

拿起已装卡掌机会在手上启动，此时按键仍控制Minecraft。首次缺少本地内容时，内屏显示“正在加载卡带”及真实下载百分比，随后显示校验/启动/恢复存档等阶段；游戏画面到达后加载提示消失。收到别人转交的卡带本身不触发下载，实际启动时才按需接收；已有完整缓存校验通过后直接复用。选中掌机时物品栏上方短暂提示“右键切换全屏模式，Esc退出全屏”，随后淡出。

右键先进入完整机身放大的全屏模式，再右键切到纯游戏画面；继续右键可往返切换，两种模式共用同一局。纯画面按原比例最大化到屏幕某一边，保留细边框，不拉伸或裁切。Esc只退出全屏、清除游戏按住状态并交还世界操作，不结束当前会话。全屏内没有常驻按键说明、玩家状态条或设置按钮。

默认惯用右手时，主手掌机由右手拿、副手掌机由左手拿；主手掌机且副手为空时双手支撑。Minecraft惯用左手设置会交换单手的左右。方向键、动作键及肩键触发时，整个实际钮帽（包括圆角和侧面）变为天蓝色，松开或退出全屏后恢复；反馈不另发输入。

要保存并结束掌机会话，先退出全屏，再切换热栏把它收进自己的背包，等待保存完成，然后在背包中右键取卡。若使用潜行取卡快捷方式，保持潜行再拿出掌机并使用，避免自动重新运行。丢弃、死亡或破坏设备应以最近已提交存档为准。插拔不会把掌机改成另一种外壳。F和F8不再承担界面切换功能，可按需绑定为游戏按钮。

放置掌机底座，正常离开游戏后手持整台掌机右键装入；底座上低位旋转展示的就是原掌机。使用底座面板开机、连接附近屏幕、加入P1即可从同一卡带存档继续。取出前先正常保存离开，再点“取出掌机”或空手潜行使用底座；机型、卡带身份及原自定义数据保持。完整说明见[掌机、底座与薄大屏](HANDHELD-DOCK.md)。

彩色或后继机型的部分兼容关系由面板提示和服务端检查，例如GBC接GB、GBA接GB/GBC、NGPC接NGP、WonderSwan Color接WonderSwan。请选择提示兼容的卡带。

FDS需在自己的游戏目录放入合法自备的8192字节 `muxi-console/firmware/disksys.rom`。游戏要求换面时，默认依次按 **E弹出 → Q换面 → E插入**。

Lynx需放入合法自备的512字节 `muxi-console/firmware/lynxboot.img`。除普通LNX卡带，刻录器接受有效的BS93 `.o` 家用程序；普通电脑的 `.o` 对象文件不能刻录。测试用原创诊断固件仅用于自有诊断，不作为通用固件提供。

## 按键和手柄

使用Minecraft自己的“选项→控制→按键绑定”，在“木犀游戏机 · 对应平台”分类中调整按钮和模拟摇杆方向。沿用MC原生的改键、冲突标记与恢复默认，键盘/鼠标及组合键保存在options.txt。首次进入会迁移旧配置，已有原生绑定优先；不再提供独立键位页面。

手柄的平台、设备/自动选择及物理按钮映射位于同一个MC原生“控制”列表，使用原生选项控件，修改后自动保存。手柄需启用并选择设备，模拟轴和扳机继续支持。

| 操作 | 默认键 |
| --- | --- |
| 常规方向 | WASD |
| 常规A / B | J / K |
| 常规X / Y | I / U |
| Start / Select | Enter / 右Shift |
| L / R | Q / E |
| N64左摇杆 | WASD；十字键另用方向键 |
| N64 A / B | J / K |
| MD A / B / C | J / K / L |
| 两种掌机全屏模式往返 | 右键 |
| 退出全屏，释放输入 | Esc |

右键与Esc保留给界面，不可同时绑定游戏按钮；F/F8可以绑定。各平台分类只在自己的游戏会话中生效，因此默认WASD不会与普通走路同时触发。N64的摇杆与十字键不同，移动类游戏通常使用左摇杆。

两种全屏模式都会拦截移动、攻击、丢物、换热栏和交换手等世界输入；此时WASD只按游戏绑定生效。Esc将游戏输入归零并交还世界操作，保留当前会话；进入设置、失去窗口焦点及退出会话也会清除按住状态。普通拿着掌机走路不会同步推动游戏角色。

MAME Pong先按Select（默认右Shift）投币，随后用左右方向控制本席球拍；当前默认左方向会使球拍下移。手柄使用左摇杆X轴，各自只控制对应球拍，松开数字方向可能保留当前位置。其他街机依驱动定义操作，必要时在本平台设置中调整。

## 连接WebDisplays网页显示面

此功能需要正常安装WebDisplays与MCEF。先按WebDisplays本身的方式建立显示面，再进入木犀游戏控制席；选择者必须有该显示面更改网址的权限。

1. 游戏中按Esc回到世界，控制席保持占用。
2. 主手或副手拿木犀控制器，潜行使用要连接的网页显示面；另一只手可保留掌机。
3. 掌机右键返回游戏，桌机从设备面板重新进入已占用的控制席。所选显示面播放实时画面，附近玩家可观看，不因观看取得ROM、存档或控制席。
4. 对同一面再次潜行使用控制器解除连接，恢复原网页。源会话结束、权限失效或显示面被正常改动后也会解除。

只连接选中的面。木犀内置屏幕无需浏览器模组；网页显示功能不能代替加入控制席。

## 当前验收范围

21平台已有原创诊断或官方无ROM电路实际运行；这不等于所有商业游戏均兼容。N64和MAME共享双席、21平台的新进程直接恢复及候选10恢复原GB卡带的结果保留为分轮证据。当前卡槽、传输、交互及世界存储范围见[本轮审核](CARTRIDGE-SLOTS.md)。实体手柄与热插拔、完整整合包、光影及音频设备听感仍分别验收。第一方发行许可及第三方精确源码交付尚未完成，候选未公开发布。
