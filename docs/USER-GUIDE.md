# PlayStation玩家指南

服务端和客户端安装相同版本。当前面向Windows x86-64、Minecraft1.21.1 / NeoForge21.1.250。游戏机不附带商业游戏或原厂BIOS，请准备自己有权使用的文件。本页介绍0.2.0的24个平台，含新增Wii、NDS、3DS及设备间连接；最终发行状态和实际验收边界见[升级工作单](PLAYSTATION-UPGRADE.md)。已发布0.1.0的历史21平台证据见[平台说明](PLATFORM-COMPLETION.md)。

0.2.0须客户端与服务端一起升级，旧版连接会在握手时被拒绝，避免进入世界后才出现加载或控制失败。已有卡带、机器UUID、存档和原有按键名称继续沿用。

## 刻录自己的卡带

1. 使用刻录机，把一张空白卡带放入窗口上方的刻录槽。
2. 点击“选择文件”，或将一个游戏文件拖入窗口。通常可自动识别；有歧义时手选平台。
3. 确认本次文件及使用的授权声明，再点击“上传并刻录”。声明默认不勾选；更换文件、平台或街机依赖后须重新确认。
4. 成功后从同一槽取出可转交的实体卡带；关闭窗口会退回槽内原物。主机、掌机与卡带分别制作，卡带不会永久绑定上传者。

街机选择原名`driver.zip`，例如驱动名为`example`时使用`example.zip`。需要parent或BIOS依赖的游戏，点“依赖”选择自己有权使用、保留原名的ZIP；不要解压后混在一个随意命名的包里。刻录器会将主ZIP和依赖准备成`.mxarc`后整体校验；已有合法`.mxarc`也可选择。模组不提供这些游戏或BIOS文件。

存档跟着掌机或桌面主机走，每台机器为每个游戏保存独立进度。卡带只携带游戏内容：同一游戏重新刻录一张卡，在原机器上仍能继续；把卡借给另一台机器，使用的是对方机器自己的进度。把整台掌机或主机交给别人，其内部已有进度也随机器转交。游戏以文件内容哈希区分，不以卡带标题或卡号区分；不同版本、汉化或修改过的文件视为不同内容。转交或拆卸前正常保存离开，已取得的本地ROM缓存无法远程撤回。

默认本地存储的ROM原件及已提交存档在当前世界的`muxi-console/content`、`muxi-console/states/machines`中，按机器和游戏内容分别保存。备份整个世界会同时保留玩家、设备、收纳盒及机器身份；客户端ROM缓存不代替世界存档。旧候选按卡保存的`states/cards`原文件继续保留，不自动导入其他机器或覆盖新进度。旧档无法可靠判断属于哪台机器，当前不提供自动迁移。云存储配置由服主在服务器外部管理，不随模组包或Git分发；未配置时直接使用世界目录。启用OSS/S3后ROM正文由客户端直传直读，世界内仍保留授权元数据和全部存档，备份方案需要同时保存云端ROM。历史路径验收边界见[机器存档与收纳盒](MACHINE-SAVES.md)。

## 合成与重塑机型

游戏机核心是合成材料，不能直接游玩。掌机用的“游戏机核心”由2铁锭、1玻璃、2红石和1铜锭合成；桌面游戏机核心由5铁锭、3红石和1铜锭合成。把原核心或已有设备与一份对应染料放入合成栏，得到指定机型。掌机与桌机使用各自的核心，重塑不会跨越物品类别。

| 染料 | 游戏机核心（掌机） | 桌面游戏机核心 |
| --- | --- | --- |
| 白色 | GB | SG-1000 |
| 淡灰色 | WS | SNES |
| 灰色 | NGP | SMS |
| 黄绿色 | GBC | 双人街机 |
| 紫色 | GBA | — |
| 蓝色 | GG | N64 |
| 橙色 | Lynx | 单人街机 |
| 黄色 | NGPC | FDS |
| 粉红色 | WSC | PCE |
| 红色 | VB，需另加1玻璃片 | NES |
| 黑色 | NDS | MD |
| 棕色 | — | A2600 |
| 青色 | 3DS | A7800 |
| 淡蓝色 | — | Wii |

重塑复制原设备的完整数据，只改变机型。机器UUID、原卡槽中的整张卡、自定义名称及其他数据保持，各游戏存档仍属于同一台机器。已装卡带必须与目标机型兼容；不兼容或卡槽异常时没有合成结果，也不会消耗原设备。不同卡带之间的进度隔离规则保持不变。空设备可以在同类机型间重塑，界面不再提供任意切换型号按钮。

## 卡带收纳盒

收纳盒是薄片式硬壳卡册，有27格，手持右键打开，潜行右键可以摆放在地面或桌面上；摆放后右键打开，布局和箱子相同。只接收游戏卡带和空白卡带，已刻录卡每格一张，空白卡可以按原有上限堆叠。普通放入、快捷移动、数字键和拖拽遵从同一限制，不能放入掌机、杂物或另一个收纳盒。

打开便携盒时，其自身所在物品栏格会锁定；关闭后即可正常移动或转交。生存模式拆除会掉落保留完整内容的整盒，里面的卡带不会散落。盒子只负责收纳，不会自动把卡装到掌机，也不会因为收到或收进一张卡而下载ROM。

## 桌机、屏幕与多人

先合成具体机型，再放置主机，空手使用打开设备面板并插入兼容卡带。可连接附近的电脑显示器；自带显示面的机体直接显示游戏画面。显示器占宽2格、高2格、深1格的空间，面板本身为薄窄框，下面有支架和底座；任意一格拆除会收起整台，只掉落一件屏幕。旧六格屏会安全缩为四格；旧单格屏周围可用时升级，受阻时保留原位，不挤掉邻块。

手持控制器接入主机，启动后选择P1；其他玩家用自己的控制器选择空闲P2等接口。可用人数取决于机型和平台，单人机台与双人机台分别提供相应接口。Esc退出全屏并释放输入，控制席仍保留；需要取卡时，在当前设备面板点“保存并离开游戏”，等待保存完成后再取出。运行或保存中不允许拔卡；电源停止不作为最新进度已提交的保证。

普通多人控制席由主控制席运行一份游戏，其他已占席玩家收取同一真实音画并提交自己的输入，不下载ROM或启动平行核心。内置屏和WebDisplays旁观也只接收音画。共享画面最高20帧/秒，复杂画面可能降低清晰度；声音为48kHz双声道。主控正常离开会保存并结束该轮，下一位重新以P1启动可继续已保存进度。

## 两台游戏机连接

双方持有已插兼容卡带的GB/GBC、GBA、NDS或3DS掌机，在控制选项中打开“游戏机连线”，或按默认F9。选择在线玩家并邀请，对方可以接受或拒绝。接受后先保存双方的单机进度，宿主临时获准读取两张卡，分别运行两台模拟机器；对方控制自己的机器并接收自己的音画。它与两个人控制同一台主机的P1/P2不同。

GB/GBC、GBA模拟硬件串口，NDS、3DS模拟本地无线；进入游戏后仍要使用游戏自己的联机入口。游戏版本、平台和玩法必须相容，不保证任意卡带可以互联。玩家可通过同一Minecraft服务器远程连接，此功能不接入任天堂官方网络或任意外部模拟器房间；本轮两客户端实测使用本机网络，公网时延另需实测。

结束时打开“游戏机连线”，点“保存并结束连线”，等保存完成再收起机器或取卡。进度仍写入各自机器；GB/GBA和NDS另有同一组合的连接快照。3DS重连创建新的无线房间，并恢复已提交的机器CPU及文件进度，传输中的网络队列不作为持久存档。NDS/3DS约每3600个模拟帧后台保存一次，正常离开再保存；意外断线以最近成功提交的进度为准。

## 掌机与机型

先用核心与染料合成机型。每台掌机容纳一张完整卡带：背包中鼠标拿起兼容卡带，右键掌机装入；空鼠标右键掌机取出。也可以鼠标拿着掌机右键明确的卡带槽装入，或右键空槽取出。悬停掌机会显示原生卡槽预览和实际卡带。插拔统一在物品栏中完成，卡带原身份、名称和自定义数据随原物品保留，满槽、不兼容和运行/保存中会拒绝插拔。

拿起已装卡掌机会在手上启动，此时按键仍控制Minecraft。首次缺少本地内容时，内屏显示“正在加载卡带”及真实下载百分比，随后显示校验/启动/恢复存档等阶段；游戏画面到达后加载提示消失。收到别人转交的卡带本身不触发下载，实际启动时才按需接收；已有完整缓存校验通过后直接复用。切换物品保留已收到的内容，重拿后从断点继续；刻录者直接复用自己选择的原文件。选中掌机时物品栏上方短暂提示“右键切换全屏模式，Esc退出全屏”，随后淡出。

右键先进入完整机身放大的全屏模式，再右键切到纯游戏画面；继续右键可往返切换，两种模式共用同一局。纯画面按原比例最大化到屏幕某一边，保留细边框，不拉伸或裁切。Esc只退出全屏、清除游戏按住状态并交还世界操作，不结束当前会话。全屏内没有常驻按键说明、玩家状态条或设置按钮。

默认惯用右手时，主手掌机由右手拿、副手掌机由左手拿；主手掌机且副手为空时双手支撑。Minecraft惯用左手设置会交换单手的左右。方向键、动作键及肩键触发时，整个实际钮帽（包括圆角和侧面）变为天蓝色，松开或退出全屏后恢复；反馈不另发输入。

要保存并结束掌机会话，先退出全屏，再切换热栏把它收进自己的背包，等待保存完成，然后在背包中右键取卡。丢弃、死亡或破坏设备应以最近已提交存档为准。插拔不会把掌机改成另一种外壳。F和F8不承担界面切换功能，可按需绑定为游戏按钮。

底座在0.2.3开发候选中改为原版容器界面（线上0.2.2仍为旧面板）。右键底座时，手持游戏先正常保存并结束；等待完成后，从下面的玩家背包把掌机放入上方单槽，不必重新拿到手上。槽中只容纳一台具体机型的掌机，支持普通点击、右键整机搬运和Shift快捷移动；关闭界面后掌机仍留在底座。运行、连线或保存期间不允许装取。

底座上低位旋转展示的就是槽中的原掌机。界面中开机、连接附近屏幕、加入P1即可从这台掌机的进度继续；底座和屏幕不保存独立进度。取回时重新打开底座，先点“保存并离开游戏”，等待槽位解锁，再直接取走掌机；没有单独的取出按钮。整机搬运保留机器身份、机型、整张卡带及原自定义数据。桌面主机在生存模式拆下再放置也保留机器身份；仍应先正常保存离开再拆除。完整说明见[掌机、底座与薄大屏](HANDHELD-DOCK.md)。

彩色或后继机型的部分兼容关系由面板提示和服务端检查，例如GBC接GB、GBA接GB/GBC、NGPC接NGP、WonderSwan Color接WonderSwan。请选择提示兼容的卡带。

FDS需在自己的游戏目录放入合法自备的8192字节 `muxi-console/firmware/disksys.rom`。游戏要求换面时，默认依次按 **E弹出 → Q换面 → E插入**。

Lynx需放入合法自备的512字节 `muxi-console/firmware/lynxboot.img`。除普通LNX卡带，刻录器接受有效的BS93 `.o` 家用程序；普通电脑的 `.o` 对象文件不能刻录。测试用原创诊断固件仅用于自有诊断，不作为通用固件提供。

## 按键和手柄

在Minecraft“选项→控制”中点击“游戏机键位绑定”，选择家用机、掌机或街机分组，再选择具体平台与键盘或手柄。键盘页将方向、操作按键、系统按键和摇杆方向分组；点绑定按钮后按新键，Esc取消本次捕获，Delete或Backspace清除。每个按钮可恢复默认，同平台冲突以红字提示。

键盘/鼠标及组合键继续保存到原options.txt，已有原生绑定保留。普通Minecraft按键页不再堆叠全部平台的游戏机按键；普通“全部重置”只重置该页可见的普通绑定。手柄页选择设备或自动选择，再调整物理按钮映射，修改后自动保存到既有手柄配置；模拟轴和扳机继续支持。

| 操作 | 默认键 |
| --- | --- |
| 常规方向 | WASD |
| 常规A / B | J / K |
| 常规X / Y | I / U |
| Start / Select | Enter / 右Shift |
| L / R | Q / E |
| N64左摇杆 | WASD；十字键另用方向键 |
| N64 A / B | J / K |
| MD A / B / C | J / K / L |
| 两种掌机全屏模式往返 | 右键 |
| 退出全屏，释放输入 | Esc |

右键与Esc保留给界面，不可同时绑定游戏按钮；F/F8可以绑定。各平台分类只在自己的游戏会话中生效，因此默认WASD不会与普通走路同时触发。N64的摇杆与十字键不同，移动类游戏通常使用左摇杆。

两种全屏模式都会拦截移动、攻击、丢物、换热栏和交换手等世界输入；此时WASD只按游戏绑定生效。Esc将游戏输入归零并交还世界操作，保留当前会话；进入设置、失去窗口焦点及退出会话也会清除按住状态。普通拿着掌机走路不会同步推动游戏角色。

MAME Pong先按Select（默认右Shift）投币，随后用左右方向控制本席球拍；当前默认左方向会使球拍下移。手柄使用左摇杆X轴，各自只控制对应球拍，松开数字方向可能保留当前位置。其他街机依驱动定义操作，必要时在本平台设置中调整。

## 连接WebDisplays网页显示面

此功能需要正常安装WebDisplays与MCEF。先按WebDisplays本身的方式建立显示面，再进入游戏控制席；选择者必须有该显示面更改网址的权限。

1. 游戏中按Esc回到世界，控制席保持占用。
2. 主手或副手拿控制器，潜行使用要连接的网页显示面；另一只手可保留掌机。
3. 掌机右键返回游戏，桌机从设备面板重新进入已占用的控制席。所选显示面播放实时画面，附近玩家可观看，不因观看取得ROM、存档或控制席。
4. 对同一面再次潜行使用控制器解除连接，恢复原网页。源会话结束、权限失效或显示面被正常改动后也会解除。

只连接选中的面。内置显示器无需浏览器模组；网页显示功能不能代替加入控制席。

## 当前验收范围

已发布0.1.0的21平台有原创诊断或官方无ROM电路运行证据；这不等于所有商业游戏均兼容。N64和MAME共享双席、冷恢复、机器存档与整合包验证均按各轮固定输入保留，具体范围见[机器存档审核](MACHINE-SAVES.md)及[原卡槽审核](CARTRIDGE-SLOTS.md)。该版第一方MIT源码和第三方对应源码已交付。

本轮重塑、原生刻录槽、分组设置、配件姿态、断点下载、OSS直传直读、普通多人音画和新增三平台已有独立Minecraft实测。设备连接以原创诊断程序核验真实串口/无线挑战与机器存档，不代表所有商业游戏兼容；精确范围见升级工作单。实体手柄与热插拔、光影、音频设备听感及公网联机时延仍需各自验证。
