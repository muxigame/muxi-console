# 木犀游戏机玩家指南

服务端和客户端安装相同候选版本。当前面向Windows x86-64、Minecraft1.21.1 / NeoForge21.1.250。游戏机不附带商业游戏或原厂BIOS，请准备自己有权使用的文件。支持平台和实测边界见 [平台说明](PLATFORM-COMPLETION.md)；当前仍是未发布开发候选。

## 刻录自己的卡带

1. 在物品栏准备空白卡带，使用刻录机。
2. 点击“选择文件”，或将一个游戏文件拖入窗口。通常可自动识别；有歧义时手选平台。
3. 确认本次文件及使用的授权声明，再点击“上传并刻录”。声明默认不勾选；更换文件、平台或街机依赖后须重新确认。
4. 成功后取得可转交的实体卡带。主机、掌机与卡带分别选择，卡带不会永久绑定上传者。

街机选择原名 `driver.zip`，例如驱动名为 `example` 时使用 `example.zip`。需要parent或BIOS依赖的游戏，点“添加街机父集 / BIOS”选择自己有权使用、保留原名的ZIP；不要解压后混在一个随意命名的包里。刻录器会将主ZIP和依赖准备成 `.mxarc` 后整体校验；已有合法 `.mxarc` 也可选择。模组不提供这些游戏或BIOS文件。

卡带存档按实体卡带身份保存，内容按哈希去重。转交卡带前正常离开游戏，让最近进度保存完成；已取得的本地ROM缓存无法远程撤回。

## 桌机、屏幕与多人

放置主机，空手使用打开设备面板。空机且关机时可切换机型；选择对应机身后插入兼容卡带，外壳会保持原机型。可连接附近的木犀屏幕；自带显示面的机体直接显示游戏画面。新屏幕默认宽3格、高2格、厚1/8格，需要六格空位；任意一格拆除会收起整面，只掉落一件屏幕。旧世界已有的单格屏保持原样。

手持木犀控制器接入主机，启动后选择P1；其他玩家用自己的控制器选择空闲P2等接口。可用人数取决于机型和平台，单人机台与双人机台分别提供相应接口。游戏中按F切换全屏/电视视角，Esc正常保存并离开。

N64和MAME由主控制席运行一份游戏，其他已占席玩家收取同一真实音画并提交自己的输入。共享画面最高20帧/秒，复杂画面可能降低清晰度；声音为48kHz双声道。主控正常离开会保存并结束该轮，下一位重新以P1启动可继续已保存进度。

## 掌机与机型

使用空掌机，先选择机型；将兼容卡带放在物品栏，再手持掌机潜行使用装入。拿起已装卡掌机会自动在手上显示正在运行的画面，此时按键控制Minecraft，游戏收到中立输入。按操作视角键（默认F）进入手持操作视角，或右键进入全屏，才按当前平台绑定操作游戏。两种视角保留同一局；操作视角键可在两者间切换。

默认惯用右手时，主手掌机由右手拿、副手掌机由左手拿；主手掌机且副手为空时双手支撑。Minecraft惯用左手设置会交换单手的左右。方向键、动作键及肩键触发时，对应真实按钮表面显示天蓝高光，松开或释放操作后恢复；高光不是新的输入来源。

Esc保存并离开，不会在仍拿着同一卡时立即重开；收起再拿出可恢复。F8释放操作、保留控制席。换热栏将掌机收进自己的背包时会停止输入并正常保存；丢弃、死亡或破坏设备应以最近已提交存档为准。取卡前须先正常保存离开，随后潜行使用取出。插拔不会把掌机改成另一种外壳。

放置掌机底座，正常离开游戏后手持整台掌机右键装入；底座上低位旋转展示的就是原掌机。使用底座面板开机、连接附近屏幕、加入P1即可从同一卡带存档继续。取出前先正常保存离开，再点“取出掌机”或空手潜行使用底座；机型、卡带身份及原自定义数据保持。完整说明见[掌机、底座与薄大屏](HANDHELD-DOCK.md)。

彩色或后继机型的部分兼容关系由面板提示和服务端检查，例如GBC接GB、GBA接GB/GBC、NGPC接NGP、WonderSwan Color接WonderSwan。请选择提示兼容的卡带。

FDS需在自己的游戏目录放入合法自备的8192字节 `muxi-console/firmware/disksys.rom`。游戏要求换面时，默认依次按 **E弹出 → Q换面 → E插入**。

Lynx需放入合法自备的512字节 `muxi-console/firmware/lynxboot.img`。除普通LNX卡带，刻录器接受有效的BS93 `.o` 家用程序；普通电脑的 `.o` 对象文件不能刻录。测试用原创诊断固件仅用于自有诊断，不作为通用固件提供。

## 按键和手柄

设备面板或空掌机面板进入“按键与手柄”，游玩时也可直接点击右上“按键设置”。每个平台独立保存键位、摇杆方向、手柄选择和按钮映射；点目标功能后按新键，Delete清除、Esc取消，改完点击保存。重复绑定会从原功能移除，页面会提示；“恢复默认”只重置当前平台。实体手柄须在这里启用并选择设备。

| 操作 | 默认键 |
| --- | --- |
| 常规方向 | WASD |
| 常规A / B | J / K |
| 常规X / Y | I / U |
| Start / Select | Enter / 右Shift |
| L / R | Q / E |
| N64左摇杆 | WASD；十字键另用方向键 |
| N64 A / B | J / K |
| MD A / B / C | J / K / L |
| 操作视角 / 切换视角 | F（设置中可改） |
| 保存并离开 | Esc |
| 外接屏幕操作 / 返回游戏 | F8 |

Esc、F8和当前操作视角键保留给游戏界面，不可同时绑定游戏按钮。操作视角键对所有平台通用，改键时会提示并清除相冲突的游戏按钮/摇杆绑定。N64的摇杆与十字键不同，移动类游戏通常使用左摇杆。

手持操作视角与全屏都会拦截移动、攻击、丢物、换热栏和交换手等世界输入；此时WASD只按游戏绑定生效。F8将所有游戏输入归零并交还世界操作，保留当前会话；进入设置、失去窗口焦点及退出会话也会清除按住状态，避免卡键。只有明确操作游戏时才采键盘和已启用手柄，普通拿着掌机走路不会同步推动游戏角色。

MAME Pong先按Select（默认右Shift）投币，随后用左右方向控制本席球拍；当前默认左方向会使球拍下移。手柄使用左摇杆X轴，各自只控制对应球拍，松开数字方向可能保留当前位置。其他街机依驱动定义操作，必要时在本平台设置中调整。

## 连接WebDisplays网页显示面

此功能需要正常安装WebDisplays与MCEF。先按WebDisplays本身的方式建立显示面，再进入木犀游戏控制席；选择者必须有该显示面更改网址的权限。

1. 游戏中按F8回到世界，控制席保持占用。
2. 主手或副手拿木犀控制器，潜行使用要连接的网页显示面；另一只手可保留掌机。
3. 按F8返回游戏。所选显示面播放实时画面，附近玩家可观看，不因观看取得ROM、存档或控制席。
4. 对同一面再次潜行使用控制器解除连接，恢复原网页。源会话结束、权限失效或显示面被正常改动后也会解除。

只连接选中的面。木犀内置屏幕无需浏览器模组；网页显示功能不能代替加入控制席。

## 当前验收范围

21平台已有原创诊断或官方无ROM电路实际运行；这不等于所有商业游戏均兼容。N64和MAME共享双席、21平台的新进程直接恢复、当前候选10的原GB卡带恢复和正常保存均已有实际结果。实体手柄与热插拔、完整整合包、光影及音频设备听感仍分别验收。第一方发行许可及第三方精确源码交付尚未完成，候选未公开发布。
