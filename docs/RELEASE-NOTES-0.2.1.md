# PlayStation 0.2.1

修复普通游玩时按键迟到、短按丢失及节拍不稳定的问题。主控制席按模拟器的原生帧率在本机逐帧运行，自己的按键直接交给本机核心；服务器继续管理实际持有、控制席、会话和存档权限。远端控制席及屏幕仍只接收音画，不下载或平行运行游戏。

- 按下和松开保留为有界输入边沿，避免一次短按在两次Minecraft tick之间消失；画面递交只保留最新帧。
- Windows使用每局独立的精确计时器，不修改系统全局计时精度或进程优先级。
- 自动存档只在实际抓取状态和机器文件时暂停；压缩、网络回执和上传在后台进行。退出或控制席变更使用独立保存令牌，旧后台存档不能提前完成新的退出请求。
- 音频按采样时长管理队列，设备打开及开始播放后清理启动积压，启动丢弃单独记数。稳定播放不持续裁剪音频；没有声音设备也不阻塞Minecraft输入和画面。

客户端和服务器须一同更新，本版使用连接协议6。卡带、机器UUID及世界中的进度位置保持；独立worker、模拟器核心和机器存档格式没有更换。发行包继续附完整第三方对应源码及许可，实际OSS/S3配置和凭据不进入包或Git。

适用Minecraft 1.21.1、NeoForge 21.1.250、Java 21、Windows x86-64；精确计时API需要Windows 10 1803或更新系统。

当前验证：60组4782项纯检查、独立Windows计时/句柄及实际音频线路检查通过；GBA真实MC专项34项通过，短按计数完整，输入到核心p95约16毫秒，两个稳定测试窗口没有新增丢样或欠供。多人12项和NDS后台/最终保存及冷恢复15项也已通过，共61项真实MC检查、5张原图逐张审核。发布状态以线上清单为准。软件回调、纹理和声音线路的测量不等于实体键盘到显示器或扬声器的物理延迟，也不代表任意商业游戏兼容性。
