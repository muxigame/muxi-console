# PlayStation 0.2.0

面向 Windows x86-64、Minecraft 1.21.1 / NeoForge 21.1.250 / Java 21。客户端和服务端需要同时升级。

- 加入 Wii、NDS、3DS，共24个平台、25款设备；NDS/3DS使用实际双屏和下屏触摸输入。
- 加入 GB/GBC、GBA 串行连接，以及 NDS、3DS 本地无线模拟。双方通过同一 Minecraft 服务器邀请并授权，分别控制自己的机器。普通多人控制席、内置显示器和 WebDisplays 统一收取主控音画，远端无需平行运行模拟器或下载ROM。
- 刻录机使用实际空白卡槽；相同内容去重但保留独立实体卡号。刻录者复用原文件，下载中切换物品保留断点，加载、校验和启动失败提供更具体的诊断。
- OSS/S3完全可选。服主显式指定外部私有配置后，客户端直接上传、下载ROM，服务器处理授权和对象元数据。未配置时继续使用世界目录；实际配置和凭据不随模组或Git分发。
- 游戏机核心通过染料配方合成为具体机型；已有设备重塑保留机器身份、兼容卡槽及进度。完善卡槽悬停预览、配件持物姿态和机型简写，删除潜行快捷装卡。
- 在Minecraft控制选项中提供独立的“游戏机键位绑定”，按设备及平台设置键盘、鼠标和手柄；键盘仍使用原options.txt。
- 修复保存事务重入、长时间加载、缓存扩展名、原生文件退出、Wii SD保存、NDS Windows异常处理，以及3DS无线状态恢复等缺陷。

升级后，原“通用机”作为合成核心使用，需要与染料合成具体机型，例如紫色染料得到GBA掌机。重塑保留原机器及兼容卡带。进度继续按机器和游戏内容保存，借卡不带走进度；整台机器转交会携带该机进度。云存储只承载ROM，已提交存档仍在世界目录，云端ROM需纳入服主自己的备份方案。

连接功能不接入任天堂官方网络或任意外部模拟器房间。3DS重连建立新的无线房间，恢复机器CPU及文件进度，不持久化传输中的网络队列。原创诊断程序的通过不等于所有商业游戏兼容；公网时延、实体手柄热插拔和实际音响听感另需验证。精确验收范围见[升级工作单](PLAYSTATION-UPGRADE.md)，操作见[玩家指南](USER-GUIDE.md)。

原创部分按MIT开源；第三方核心、派生补丁及运行库保留各自许可，完整对应源码和原始许可证随发行JAR交付。游戏ROM和原厂BIOS由玩家自行准备，模组不提供第三方游戏下载。
