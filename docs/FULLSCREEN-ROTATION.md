# 双屏布局、全屏旋转与Minecraft覆盖层

## 左右双屏布局候选

2026-11-09，0.2.3-dev.4未发布。双屏纯画面全屏增加一个原生“布局”按钮，在上下排列和左右并排之间切换。上屏放左、下屏放右，分别从现有帧取各自像素；每块保持原方向和自身比例，以共同高度居中最大化，保留细边框及间隔。3DS上下屏宽高比不同时分别适配，不把下屏拉宽到上屏比例。

布局独立于整组四向旋转；下屏触摸先逆旋转，再根据当前显示框映射到原下屏，间隔与上屏不会发送触摸。触摸框使用实际取整后的绘制边界。带机身模式继续显示原模型的实体上下屏，切回纯画面恢复所选布局，不改模型或核心。

现有本地schema1配置的`games`旋转字段保留，新增`layouts`记忆`平台/ROM内容SHA256`的左右选择；旧配置没有布局字段时仍为上下排列。两个设置原子保存且互不覆盖，客户端间独立，与机器和世界存档无关。不增模拟器进程，不复制ROM、视频或音频，也不更改共享流或世界屏幕排列。

最终候选`build/dual-layout-02`主包1286431字节，SHA256 `e9096a9670effb21313eafc5981502be54987f7ccead5a5a4338618af9b709f7`，62组5005项通过，其中新增几何123项覆盖NDS/3DS各自比例、宽窄窗口、旋转组合及触摸间隔。相对前轮旋转候选，既有条目只变GameScreen及内部类、显示偏好和版本元数据，另增DualScreenLayout；核心、运行库、网络及资产保持原字节。

统一`client-2/runs/console-dual-layout-01`，runId `9fb0de790ea841ceb311e4c15e60b120`，原创NDS卡75条记录通过，5张原图逐张实审，其中4张再独立读取真实PNG确认上下屏颜色。验证左右布局保持0°、四向侧布局触摸真实黄/蓝、上屏/间隙拒触、机身往返、设置独立读回与重新打开恢复、F3/原生聊天及第二客户端收信；全程同一worker推进。正常退出后独立核对世界状态文件大小和SHA。

一个worker及三MC进程自然退出0/native清空，约908MB运行payload及唯一准备正常回收。[本机审核](../build/dual-layout-02/review.json) SHA `4e72efc8…867c112`。未改干净源或生产；3DS本轮仅几何覆盖，不扩大为3DS原生、商业游戏、物理输入或性能验收。以下为前轮已冻结的旋转候选记录。

## 四向旋转与原生覆盖层候选

2026-11-09，0.2.3-dev.3开发候选，未发布。原版底座与Wii修复继续保留；本轮只改客户端呈现和输入桥，运行库1.0.1保持原字节。

全屏右上角保留一个原生“旋转”按钮，按顺时针0/90/180/270度循环。四向可以覆盖向左、向右书本握持及倒置，不增加任意角度设置。机身模式旋转完整设备及内屏，纯屏模式旋转整组双屏；始终按原比例适配窗口。鼠标先逆旋转再映射到原触摸屏，不改变模拟器收到的屏幕身份和坐标。切换方向不重启核心。

每个客户端按`平台/ROM内容SHA256`记忆方向，文件为`config/muxi-console-display.json`。同内容换卡复用方向，不写入卡带、机器或世界存档；另一台电脑可以独立选择方向。

全屏黑底已移除，画面外露出真实世界。旧GameScreen只绘制一层不透明矩形；Minecraft的GameRenderer在Screen之前已经渲染世界，黑底并没有跳过世界渲染。此次移除遮盖不增加第二遍世界渲染；实际成本仍与场景、光影和硬件有关，本轮没有做帧率基准或给出性能百分比。

原生F3调试信息与聊天绘制在游戏之上，其他原版状态栏仍隐藏。聊天/命令遵从Minecraft原绑定和聊天权限，默认T、/。打开聊天清除游戏键与指针；真实ChatScreen负责编辑、历史、建议和发送，Enter或Esc回到同一授权会话与方向。开门键对应字符在释放前被精确拦截，避免初始多出`t`或`//`，其他字符正常交给原版。F3基本信息已接入，未重新实现各类F3组合操作。
