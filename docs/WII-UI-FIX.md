# Wii画面与原版界面候选（0.2.3-dev.2，未发布）

Wii仍使用Dolphin。实际WBFS黑屏的原因是前端在每个`retro_run`前强制绑定展示帧缓冲，Dolphin却缓存了自己的EFB绑定并跳过重复设置，导致实际OpenGL状态与缓存不一致。现在仅Wii不再执行这次绑定，通过公开的framebuffer回调提供展示目标；其他平台继续原行为。核心DLL、默认EFB选项、线程检查及15秒超时都未改。

用服务器现有WBFS的完整校验副本，在独立临时profile中对照：原worker7200帧只有8帧非黑，新worker7200帧有7013帧非黑并持续出图。按标题要求同时按A+B后，实际进入存档创建/选择菜单；不是只看到启动标志。默认MC键位为J+K。早期每60帧采样曾遗漏画面，已在本地原记录中更正，最终依据逐帧统计和完整对照。没有更换ROM，也没有读取或写入生产玩家的机器存档。

加载提示现在从真实会话平台生成，Wii显示“正在启动 Wii”。刻录机、底座和卡册已经使用原生容器；连线、分组键位和普通按键页已经使用原版控件。这次将仍使用旧深色面板的主机管理页及旧兼容掌机页统一为原版灰色面板和按钮，保留现有操作。主机管理页仍是管理面板，本轮没有另加桌机卡带容器。游戏画面与机身渲染保持。
