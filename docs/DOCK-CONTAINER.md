# 底座原生掌机槽（0.2.3开发候选，未发布）

右键底座打开与刻录机一致的原版容器界面，上方一个掌机槽，下方是玩家背包。打开时正常保存并结束手持游戏，等待完成后直接从背包装入，避免重新拿起掌机又自动开机。普通点击、右键、Shift和数字键都移动整台掌机；关闭界面后机器留在底座。取消单独的取出按钮、手持直接安装和潜行取回入口。

底座内仍可开机、连接屏幕和选择控制席。游玩后重新打开，使用“保存并离开游戏”，保存提交后槽位解锁，再取回原机。机内卡带、机器UUID、名称和其他组件保持。运行、连线和保存中的机器或卡带不能装取；电源停止也不能绕过保存保护。多个玩家打开的是同一底座库存。原有 `docked_handheld` 世界数据格式及低位旋转模型保持。

进入游戏前正常关闭底座容器，恢复玩家普通背包；这不结束刚加入的游戏。自定义控制操作绑定当前容器ID和底座身份，原生物品操作继续使用Minecraft菜单同步。
