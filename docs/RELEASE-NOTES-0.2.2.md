# PlayStation 0.2.2

本地候选，尚未发布。

修复JEI中游戏机核心按U看不到机型用途、搜索GBA等名称找不到设备的问题。核心和25款机型按实际型号分别索引，每款设备都有对应的核心、染料及必要玻璃板配方；已有设备也能查看重塑用途。显示配方不替换服务器的真实合成逻辑，原机器身份、完整卡带、名称及存档继续保留。

安装文件拆为三份：

- 主体`muxi-console-0.2.2+mc1.21.1.jar`约1.25MB，客户端与服务端安装。
- 固定运行库`muxi-console-runtime-1.0.0+mc1.21.1.jar`约159MB，仅客户端安装；核心、独立工作进程和系统资源仍按原大小和SHA256校验。以后只修改主体时，未变的运行库无需重新下载。
- `muxi-console-runtime-1.0.0-sources.zip`是约606MB的完整对应源码附件，提供独立下载，玩家运行游戏无需安装。

整合包会自动安装对应文件；手工安装须移除旧的单一大JAR，并把主体与运行库放入客户端的`mods/`。服务端只需主体。JEI是可选集成，未安装时其余功能仍可使用。

本次没有更换模拟器核心、工作进程、存档格式或连接协议；0.2.1的实时输入与音频修复保持。easycat已在0.2.1线上复测《节奏天国》，确认按键和声音均正常。

构建与验证状态待本轮实际Minecraft验收后补记。
