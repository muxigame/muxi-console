# PlayStation 0.2.4

随客户端整合包与服务端同批发布。

- 台式主机改为和底座一样的原版单槽界面：右键主机打开“游戏主机”面板，卡带或光碟直接从背包放入/取出；面板含开机、连接屏幕、P1–P4控制席、保存并离开和按键设置。运行或保存时槽位锁定，界面提示当前不能操作的原因。
- 台式主机自带一个控制席：插好卡带/光碟、开机后即可直接用P1开始，不再必须先接控制器；每接一个控制器再多一个席位，上限按机型。
- 底座同样显示操作提示，并补上“按键与手柄”入口。
- 修复Wii没有声音：Dolphin在自己的线程上送出声音，旧运行库在单帧调用以外收到的样本全部丢弃。现在这些样本会进入下一帧的音频，NDS等其他平台的取样方式不变。
- 修复旋转和双屏左右布局只在全屏窗口生效、连接的大屏幕仍显示原方向：大屏现在按当前玩家的旋转/布局显示，转发给旁边其他玩家（含网页屏幕）的画面也已按同样方式排好。

安装文件：

- 主体`muxi-console-0.2.4+mc1.21.1.jar`，客户端与服务端安装。
- 运行库`muxi-console-runtime-1.0.2+mc1.21.1.jar`，仅客户端安装；含Wii声音修复，主体要求至少1.0.2。
- `muxi-console-runtime-1.0.2-sources.zip`为运行库1.0.2的完整对应源码附件，独立下载，运行游戏无需安装。

整合包会自动替换；手工安装须同时换掉0.2.3主体和1.0.1运行库。服务端只需主体。
